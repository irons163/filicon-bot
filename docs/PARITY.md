# Filicon / Grok Bot 0.18 功能 parity matrix（current implementation）

本矩陣保留固定的 48 個 parity ID，對照目前 macOS Swift 實作。`complete` 表示該列所述能力有歷史實作證據，不代表原版所有細項均已重新核驗；`partial` 表示仍有功能、接線或驗證缺口；`NA` 表示該列是來源 runtime 的實作細節，不是 macOS 產品行為。這不是「原版功能全部都有」的保證。

2026-09-18 核對 reconstructed 原始碼後，修正為 44 筆 `complete`、3 筆 `partial`、1 筆 `NA`（`UPD-04`）。`AGENT-01` 已補受審批的模型 `CreateAgent`／`UpdateAgent`、own-profile `update_state(profile.set)` 及 own-agent `memory.write/forget`；仍限制在有 agent 身分的群組／mailbox，不改私人 persona，也未涵蓋共享記憶及其他 update_state 路由，因此維持 partial。其他列的驗證欄保留歷史紀錄，不表示本次重新驗證。細項見 [協作核對紀錄](Agent-collaboration-parity.md)。
